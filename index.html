Suvidha Diagnostics

Desktop version 1.0.32. Internet access is required.

  • Download for Windows x64
  • Download for macOS (Intel and Apple silicon)
  • Download for Linux x64 (Ubuntu 24.04)

The app updates itself when it opens and asks to restart when a newer version arrives while it is open.

No installer carries a Microsoft or Apple signing certificate. Windows may show a SmartScreen prompt. On a Mac, open the archive, move the app to Applications, then allow it once under System Settings → Privacy & Security → Open Anyway. On Linux, make the AppImage executable (chmod +x) and run it. App updates use a separate cryptographic signature checked by Tauri.
